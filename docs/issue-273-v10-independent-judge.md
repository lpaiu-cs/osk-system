# v10 새 100개 — 독립 판정 30건

2026-11-07. v10 실행(F101–F200)의 논지 판정 비율(실행자 85–87%가 결론·범위 변경)이 경계를 넓게 그은 탓인지 확인하려고, 실행 결과를 보지 않는 독립 판정자가 30건을 다시 판정했다.

## 고정 조건

- 표본: F101–F200을 `sha256("issue273-v10-independent-judge-20261107" + id)` 순서로 정렬한 앞 30건. 판정 전에 표본과 지시문 해시를 고정했다.
- 판정자: `gpt-6.1-terra`, medium, 도구 없음(Codex CLI 0.167.0-alpha.3.2, `--ephemeral`, 훅 끔). 사용자 지시로 독립 평가에는 Astra 대신 Terra를 쓴다.
- 입력: 변경 직전 본문(근거 절 제외)과 그 커밋의 diff뿐이다. 실행자 판정·직접 판독·실행 지시문은 주지 않았다.
- 판정 기준: v10의 네 판정 정의에 사용자가 정한 경계를 넣었다. 기존 결론의 사례 적용과 상태·진척 전환은 세부다(v7·v8). 직전 본문에 이미 있는 규칙·조건을 다시 적은 것은 새 결론이 아니라고 명시했다.
- 추가 응답: 논지와 세부가 섞였는지(mixed), 섞였다면 더한 글 가운데 세부의 비율(detail_share).

- 불일치 2건. F160은 판정자·terra가 논지 불변, sol이 결론·범위 변경이다. F197은 판정자만 논지 불변(사전 등록 기준에 따른 수렴 통과를 상태 전환으로 봄)이다.

## 해석

v10의 높은 논지 비율은 경계를 넓게 그은 탓이 아니다. 독립 판정도 77%를 냈고 실행자와 대부분 일치했다. 장치가 거의 처치하지 않는 직접 원인은 "논지와 세부가 섞인 커밋은 전체를 보존한다"는 규칙이다. 다른 노드가 기대는 노드의 변경은 대부분 새 결론 하나에 그보다 많은 세부를 함께 싣는다.

11-04에 섞인 변경을 건너뛴 근거는 두 가지였다(abstraction-review.md §3). 그 커밋은 논지 때문에 어차피 일어나므로 변경 빈도에 더하는 비용이 없고, 그 안의 사본은 기대는 곳이 다시 바뀔 때 섞이지 않은 변경으로 드러난다. 대신 첫 기록인 세부가 본문에 남아 노드가 자라는 것은 감수했다. 이번 표본에서는 그 감수한 비용이 주된 경우다. 30건 중 23건이 섞였고 16건은 더한 글의 절반 이상이 세부다. 판정자가 논지 불변으로 본 7건에서 실행자가 옮긴 것은 sol 2건, terra 1건이다.

## 한계

- 판정자는 실행자 하나와 같은 모델이다. 결과를 보지 않았으므로 독립성은 지켰지만 판단 습관이 비슷할 수 있다. F160에서 판정자는 terra와 같고 sol과 달랐다.
- 30건 한 번씩이다. 판정자의 반복 일관성은 재지 않았다. 새 100건은 23개 노드에서, 표본 30건은 16개 노드에서 나왔다.
- detail_share는 판정자의 어림이며 글자 수를 잰 값이 아니다.
