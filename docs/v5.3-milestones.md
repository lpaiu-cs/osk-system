  옮겼다. 옮긴 항목의 본문은 원래 문서에 두고 여기서는 가리킨다.
- 상태: 릴리스 PR #237(2026-10-23). 출시 전 점검에서 찾은 Claude 사본 결함 둘을 릴리스 PR #239·#241로

## v5.2.0 적용 뒤 관측

- [ ] **정기 성장 실행의 첫 주(#175).** 묶음당 시간과 토큰, Scope 작업 단가, 묶음 첫 요청의 냉시작,
  공급자별 작업:검토 비, 주간 한도 조정의 첫 계산을 잰다. 결정 댓글의 추정값(작업당 12만~15만 토큰,
  묶음당 8분)을 이 실측으로 고친다. → v5.3.1(첫 주가 10-26에 찬다).
- [x] **훅 지연(#192).** 이슈 본문의 두 표를 같은 방법으로 다시 잰다. 입력 훅의 10초 초과 비율과 정상
  회차 중앙값, 세션 시작·Stop의 중앙값·상위 10%·시간 초과다. 이 결과로 이슈를 닫는다.
  - 2026-10-23 재측정: 네 훅 모두 v5.2.0 적용 뒤 시간 초과가 0회다. 그 전에는 입력 훅이 29%였다.
  - Stop 중앙값은 0.6초로 9월 수준이다.
  - 입력 훅은 v5.2.1 창에서 중앙값 0.95초다.
  - 세션 시작 중앙값은 4~5초에 머문다.
  - 이 결과로 닫았다.

## 옮긴 평가

순서는 #19가 먼저다. 노출 순위(#170)와 재사용 평가(M6)는 바꾸기 전과 뒤를 이 기준선으로 비교한다.
노출 순위는 기준선보다 먼저 들어갔다. 계수를 모두 0으로 두면 BM25 순서와 같으므로, 같은 빌드에서 전후를
비교할 수 있다.

- [ ] 고정 과업·vault로 표면 효용을 반복 측정하는 기준선(#19). → v5.3.1.
- [ ] M6 자연 검토와 다음 작업의 재사용 —
  [v5.2 계획](v5.2-milestones.md#m6-자연-검토와-다음-작업의-재사용을-입증한다). → v5.3.1.
- [ ] M5 Scope→Domain 승격과 주장 분화의 의미 품질(#178) —
  [v5.1 계획](v5.1-milestones.md#m5-scope에서-domain으로-승격하고-주장을-분화한다). 평가 규약부터 정한다.
  → v5.3.1.
- [ ] 처리 순서의 효과 — [v5.2 계획](v5.2-milestones.md#측정호환-이슈)의 마지막 항목. v5.2.0에서 재지
  않았다. → v5.3.1.
- [ ] [v5.1 계획의 미룬 설계](v5.1-milestones.md#미룬-설계) 가운데 닫히지 않은 것:
