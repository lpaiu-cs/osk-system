# v5.3.0 운영 효과 관측 마일스톤

v5.2.0이 바꾼 성장 경로를 인스턴스에서 관측하고, v5.2.0에서 옮긴 효과 검증과 의미 품질 평가를 닫는다.
v5.2.0은 정기 성장 실행을 하루 묶음으로 돌리고 그 한도를 주마다 정한다(#175). 또 훅이 전사를 읽지 않게
했다(#192).

- 작성일: 2026-10-19. 같은 날의 사용자 결정에 따라 #178·#19·M6과 #192·#175의 배포 뒤 관측을 v5.3.0으로
  옮겼다. 옮긴 항목의 본문은 원래 문서에 두고 여기서는 가리킨다.
- 상태: 계획. 관측은 v5.2.0을 인스턴스에 적용한 뒤 시작한다.
- 추적: GitHub 마일스톤 v5.3.0.

## v5.2.0 적용 뒤 관측

- [ ] **정기 성장 실행의 첫 주(#175).** 묶음당 시간과 토큰, Scope 작업 단가, 묶음 첫 요청의 냉시작,
  공급자별 작업:검토 비, 주간 한도 조정의 첫 계산을 잰다. 결정 댓글의 추정값(작업당 12만~15만 토큰,
  묶음당 8분)을 이 실측으로 고친다.
- [ ] **훅 지연(#192).** 이슈 본문의 두 표를 같은 방법으로 다시 잰다. 입력 훅의 10초 초과 비율과 정상
  회차 중앙값, 세션 시작·Stop의 중앙값·상위 10%·시간 초과다. 이 결과로 이슈를 닫는다.
