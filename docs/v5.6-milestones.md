## v5.6.0

### 지식과 중심성 (#273)

- [x] **헌법 재정의(#309).** 지식은 관측을 설명하는 가설, 반성적 평형과 통섭, 중심성의 두 축(설명적 E·의존적 D),
  관측 불변과 조건·반례, 근거 절 → 관측 절 `# 관측`.
- [x] **시행(#310).** 시행령 §1 5항·§7 1·2항, Mechanism §8 6항의 C(v) = (E(v), D(v)), 엔진의 관측 절 인식과 E 계산.
- [x] **중심성 셈법(#311).** R은 참조의 유무를 센다 — 같은 참조의 반복은 하나로 세고, 자기 참조·허브가 거는 참조·
  관측 절 안의 Link는 세지 않는다. 검색 순위는 D만 쓴다(11-09 사용자 결정).
- [x] **일괄 이행은 `osk doctor --migrate`로(#311·#313).** `osk doctor`가 남은 이행을 점검하고(읽기만), `--migrate`가
  계획을 보인 뒤 사용자의 확인을 받아 정한 순서로 적용한다 — v5.4 근거 절, v5.2 옛 자리 인용 기록의 루트 `_cited/`
  이관, v5.6 `## 근거` → `# 관측`. 적용은 잠금 안에서 확인받은 대상과 원본 해시를 대 본다(11-09 사용자 결정).
- [x] **Domain 재사용의 경로(#273 질문 3 — PR #314).** 대화 검토는 결속 scope의 허브 트리만 싣는다. 새 노드를 쓰기
  전에 그 주제로 검색해 다른 scope와 Domain의 비슷한 노드를 찾게 하고, 표면은 search를 한 번도 부르지 않은 세션의
  `create_node`를 거부한다(시행령 §3 8항, Mechanism §6-2 10항, 11-10 사용자 결정). 참조 수의 실측은 사용자가 직접
  한다(질문 4).

### 정기 성장 실행 (#301·#306 — PR #312)

- [x] 공급자별 예산을 없애고, 공급자는 주간 사용률 0.9에 닿으면 쉰다. 하루 한도는 유입만으로 정한다.
- [x] 작업자 이상은 그 큐만 멈추고, 진척 없는 묶음 하나로 그날을 멈추지 않는다.
- [x] 같은 scope의 작은 꼬리를 9턴까지 한 Scope 묶음에 묶는다.
- [x] 하루 실행을 기기 기록에 남기고, 묶음 없는 날(실행이 시작되지 않은 날 포함)이 이어지면 세션 시작이 알린다.
- [x] 재검토 대행(Mechanism §4-1 4항)은 그날 재검토 큐의 완료로 판정한다(#301).
- [x] 대화 검토 적체와 예상 토큰을 `osk doctor --vault`가 보이고, `growth run --daily --backlog`가 일괄로 돈다.
