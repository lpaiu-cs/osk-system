# 2026-09-09 코드 리뷰 1차 수정

기준은 운영 인스턴스의 관리 파일과 일치함을 확인한 v3.13.0,
`635186d650b91a757778ac150bc00dca18a9d1d7`이다.
수정은 `codex/review-fixes-20260909` 브랜치에 격리했다.
이 문서는 로컬 수정과 검증을 기록하며 릴리스·운영 배포를 뜻하지 않는다.

## 수정 범위

| 리뷰 항목 | 결과 | 변경 |
| --- | --- | --- |

발행 스냅샷 생성은 기존 표준 라이브러리 복사와 릴리스 검증 함수를 사용한다.
복사 도중 변경된 원본을 원자적으로 묶는 파일시스템 스냅샷은 아니지만,
완성된 사본을 검사하고 그 검사한 바이트를 설치한다. 발행 시 전체 검증 대상의
복사 비용이 추가되므로 실제 병목으로 측정되면 파일시스템 스냅샷을 검토한다.

## 검증

정식 회귀 검사: **1,498 통과 / 0 실패 / 4 생략**. 생략한 네 검사는
Windows가 보존하지 않는 POSIX 권한 비트 검사다. 기존 1,403개 검사에
이번 결함과 발행 보완 반례를 검증하는 95개 검사를 추가했다.
정본 검증기: **PASS**.

적대 시험: 기반 수정 `e74a37d`에서 **2,697 통과 / 0 실패**, 9회, seed 1.
실제 pending transaction 6회, rollback 3회, 부분 적용 3회,
공격 차단 3회를 관측했고 종료 시점을 놓친 시행은 없었다.
이번 무작위 시행에서 roll-forward 적중은 0회였으며,
이 결과를 모든 장애 시점의 포괄적 검증으로 해석하지 않는다.

Windows 가상환경 launcher와 실제 Python 자식의 PID가 다른 조건도 별도로
측정했다. launcher 종료 후 실제 자식 프로세스의 종료를 핸들로 확인했다.
`git diff --check`와 동기화·발행·쓰기 경계의 독립 교차 검토도 완료했다.

PR #54의 1차 리뷰에서 `MAP .github/`가 스냅샷의 점 디렉터리 필터에 걸리는
회귀를 재현했다. 명시된 MAP 출처의 최상위 구획을 보존하도록 수정했다.
점 디렉터리 전체·내부 단일 파일·`./.github/` 발행, 미지정 점 디렉터리 제외,
비밀값 차단을 검사하는 8개 회귀 검사를 추가했다.
보완 후 전체 회귀 1,498/0/4와 정본 검증 PASS를 확인했다.

Windows, Python 3.12.9 및 운영 가상환경의 실제 MCP 의존성을 사용한다.
회귀·적대 시험은 임시 vault에서 실행하며 운영 데이터를 수정하지 않는다.
실행 명령은 저장소 루트 기준이다.

```powershell
python _governance/_engine/tests/test_regression.py
python _governance/_engine/tests/test_adversarial.py --trials 9 --seed 1
$env:PYTHONPATH = "$PWD/_governance/_engine"
$env:OSK_VAULT_ROOT = "$PWD"
python -m osk.validate
```

## 남은 항목

- **evict와 기억 교체의 내구성:** 현재 evict 기록이 파일 교체보다 앞선다.
  순서만 바꾸면 반대쪽 장애 구간이 생긴다. 제거 내용·전후 이미지가 있는 영속
  outbox, 재시도 중복 방지 키, 쓰기·동기화 진입점의 복구를 함께 구현해야 한다.
- **네트워크 중 전체 변경 잠금:** fetch/push를 잠금 밖으로 옮기려면 Git 작업과
  변경 적용 사이의 경계를 함께 보장해야 한다. 이번 수정에는 포함하지 않았다.
- **인과 극대 계산의 제곱 증가:** 같은 키의 이력이 커질 때 개선이 필요하다.
  현재 운영 규모에서 우선 처리할 장애로 확인되지 않아 이번에는 유지했다.
- **raw 변경 후 검색 캐시 재생성:** 참조 대상의 존재·완전성 검사와 검색 본문
  캐시를 분리하는 후속 변경이 필요하다.
