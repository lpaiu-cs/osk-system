# v10 새 100개 직접 검토

F101–F200의 원래 diff 100개와 양 모델 판정 200개를 직접 읽었다. 실제 본문 변경 13회(7개 사례)는 저장 diff와 대응 출처를 대조했다. 보존 사례는 원래 diff·판정 이유와 필요한 직전 문맥을 검토했다. 모든 원 대화 전문이나 과학 실험 자체를 재검증한 것은 아니다.

| 모델 | 적절 | 경계·허용 가능 | 경미한 분류·처리 오류 | 실질적 정보 훼손·허위 출처 연결 |
|---|---:|---:|---:|---:|
| 6.1-sol | 99 | 1 | 0 | 발견 0 |
| 6.1-terra | 93 | 4 | 3 | 발견 0 |

경계는 오답이 아니다. 경미한 오류도 실행 전체 실패와 분리한다.

## F102 — 경미한 분류·처리 오류
Terra는 추가 실행 수치를 신뢰도 변경으로 보았지만, 직전 문서에 발행 CI·전체 행렬 통과와 라이브 파일 일치가 이미 있었다. 새 결론보다 검증 이력 상세화에 가깝다. 불필요한 본문 잔류이며 정보 손실은 없다.

## F106 — 경미한 분류·처리 오류
Terra가 새 적용 한계라고 든 단계103·104·108 조건은 직전 본문에 이미 있었다. 기존 조건을 다시 적은 수치 요약을 결론 변경으로 과대 분류했다. 출처가 확인되어 근거 절 이동이 더 적절하다.

## F160 — 경미한 분류·처리 오류
Terra는 사용자 연구 방향 전환을 진행 이력으로 읽어 논지 불변으로 분류했다. 결론·범위 변경이 맞다. 다만 kept여서 사용자 지시는 그대로 남았다.

## F120 — 경계·허용 가능
같은 가설에 새 대조 증거가 붙은 경우다. Sol의 신뢰도 변경이 더 직접적이나 Terra의 범위 변경도 새 실험 범위를 중시한 해석이다. 둘 다 보존하여 결과 차이가 없다.

## F128 — 경계·허용 가능
출처는 배포 지시일 뿐 완료 보고가 아니다. Sol의 held가 미해결 상태를 더 잘 드러낸다. Terra도 연결 미확인을 명시하며 kept했으므로 허위 완료 입증이나 정보 훼손은 아니다. 출처 미확인 시 keep/held 경계가 남는다.

## F174 — 경계·허용 가능
원인이었다→때문으로 보고되었다를 확실성 변화로 볼 여지는 있으나 전용 문서로의 정리에 가깝다. Terra의 결론·범위 분류보다 Sol의 논지 불변이 자연스럽다. 결과는 둘 다 kept.

## F181 — 경계·허용 가능
참조 정돈 예외로 본문에 남길 수도 있고, 이미 명시된 역사적 주장과 대응하는 근거 줄로 이동할 수도 있다. Sol이 추가한 상세도 실제 펼친 출처에 있다. 어느 쪽도 오답 처리하지 않는다.

## 평가 한계
이 수치는 독립된 정답 라벨에 대한 정확도가 아니라 이번 수동 평가다. 각 모델 1회 결과이며 두 모델의 일반 능력 차이를 확정하지 않는다. 알려진 출처 날짜 경로와 delete 동작은 이번 표본에서 검증되지 않았다. 전부 날짜 미상인 표본의 날짜 처리만 확인했다.

F181: read_cited 첫 full 응답은 6,000자에서 잘렸으나 max_chars=10000 재호출로 8,402자 전문을 받았다. 추가 수치는 이 두 번째 응답에 있으므로 미열람 환각이 아니다. 첫 반환에는 긴 시스템성 목표 문구가 포함되어 읽기 효율 문제는 남는다.
