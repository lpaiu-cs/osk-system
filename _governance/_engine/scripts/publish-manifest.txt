# 발행 매니페스트 v2 — 무엇이 공개 미러로 나가는가
# ─────────────────────────────────────────────────────────────
# 근거: Mechanism §1 1항 — "공개 repo는 system이 참조하지 않는 발행 미러이며,
# 발행 범위는 allowlist가 정한다."
#
# 구 절차(sync-template.sh)는 **cherry-pick 기반**이라 사설과 공개의 경로가
# 같다는 전제 위에 있었다. v2는 사설 트리에서 공개 트리를 **빌드**하는
# export 모델이며, 이 파일이 그 사상의 정본이다. v2.1에서 통치 구획이
# 사설·공개 모두 `_governance/`가 되어 사상은 항등이지만, 범위의 정본이
# 이 파일이라는 사실은 변하지 않는다.
#
# 형식:
#   MAP  <사설 경로> -> <공개 경로>     끝이 '/' 이면 트리 전체
#   DENY <경로 조각>                    대상 안이라도 이 조각을 포함하면 제외
#   SKEL <공개 경로>                    빈 디렉터리 표식(.gitkeep)만 만든다
#   KEEP <공개 경로>                    공개에만 사는 파일 — 지우지 않는다
#
# 범위를 넓히는 것은 이 파일의 개정이다. 코드를 고치지 않고 여기만 보면
# 무엇이 나가는지 알 수 있어야 한다.

# ── 발행 대상 ───────────────────────────────────────────────
# 통치 문서·사료와 엔진 구현.
MAP  _governance/ -> _governance/

# 운용 문서와 MCP 설정 예시.
MAP  docs/ -> docs/
MAP  .mcp.json.example -> .mcp.json.example
# 대장 병합 규칙 — 다기기 인스턴스의 union merge (Mechanism §3 1항)
MAP  .gitattributes -> .gitattributes

# ── 공개에만 사는 것 ────────────────────────────────────────
# 사설에 원본이 없으므로 사상 대상이 아니다. 매니페스트가 "없는 것은 지운다"를
# 원칙으로 삼으므로, 지우지 않을 것은 여기에 명시해야 한다.
KEEP LICENSE
KEEP .gitignore
KEEP README.md
# 비준증빙과 릴리스 워크플로는 **정본에서 만들어져 정본에 산다**(Mechanism
# §1-2 2항). 사설에 원본이 없으니 MAP 대상이 아닌데, KEEP에도 없으면 "없는 것은
# 지운다"에 걸려 발행이 그 둘을 지우고 커밋한다 — 비준증빙이 HEAD에서 사라진다.
KEEP release.json
KEEP .github/workflows/release.yml

# ── 대상 안에서도 나가지 않는 것 ────────────────────────────
# 대장은 이 인스턴스의 권위 기록이다 — 노드 id·해시·사유·세션 키가 들어 있고
# 프레임워크가 아니라 개인 이력이다.
DENY _ledger/
# 운영 세션 기록과 원자료.
DENY _raw/
DENY _sources/
# 도구·빌드 부산물.
DENY __pycache__/
DENY .DS_Store
DENY .write.lock
DENY osk-sync.lock

# ── 빈 골격 ─────────────────────────────────────────────────
# 내려받은 사람이 자기 인스턴스를 시작할 자리. 내용은 나가지 않는다.
SKEL = Scope/
SKEL = Domain/
SKEL = Person/
