# 시행령 (Bylaws)

> 헌법([[Constitution]]) 아래의 운영 기본값. 개정은 판례 축적(§7) 또는 사용자 지시로 — 헌법보다 가볍게 움직인다.

## §1. Working Memory 운영

- 에이전트 후보 제출: **세션당 3건**, 출처 스코프 표기 + 제안 배선 힌트 첨부 의무.
- 사용자 직접 투입: 무제한. (번뜩이는 생각의 계승 통로)
- 용량 30 = **주의 예산**(저장 한도가 아니라 가시성 회전 단위). 신규 유입은 절대 막히지 않는다.
- Eviction(밀려남) 우선순위: ①무히트 중 가장 오래된 것 ②히트 있으나 응고 미달 ③응고 후보(최후순위). **면제는 없다 — Working Memory에 영생은 없다. 영생은 서명으로만.**
- 후보는 검색에서 "지식"으로 회수되지 않는다(후보 표기).

## §2. 응고 (Consolidation)

- 후보가 **서로 다른 맥락에서 2회 회수**되면 응고 후보로 부상 — WM 상단 + 다이제스트 표기.
- 회수 히트는 eviction 우선순위를 낮춘다(쓰이는 후보는 잘 잠들지 않는다) — 단 면제는 아니다(§1).
- **응고 상태는 WM 체류와 무관하게 엔진 DB에 영속한다.** 응고 후보가 evict되어 휴면층에 가도 지위는 소멸하지 않는다.
- **응고는 휴면을 관통한다**: 휴면 항목이 유사성으로 재부상하면 그것이 새 맥락 회수로 계수된다 — 재부상 메커니즘이 곧 "다른 맥락 재조우" 감지기다. 슬로우버너는 죽지 않고, 잠들었다가 자기 맥락이 도착할 때 돌아온다.

## §3. 다이제스트

- 주 1회, 데몬이 생성: 응고 후보 / 신규 후보 / 심판 사건 요약.
- **읽기는 선택이다.** 처리 의무 없음 — 죄책감 큐 금지.

## §4. 승격 워크플로우

1. 사용자가 승격 판정 (WM 방문 또는 다이제스트에서).
2. 엔진이 그물 검색 → 관련 노드·배선 초안·긴장 후보 제시.
3. **사용자가 서명 한 줄 작성** (본문 첫 줄, 사용자의 말).
4. 엔진이 서명에서 엣지 추출 + 추가 엣지 제안 → 사용자 예/아니오.
5. 엔진이 실행: 파일 이동, 엣지 기입, frontmatter.

## §5. 본문 규범

- LTM 노드 본문은 주요 링크의 의미를 **한 줄씩 산문으로 서술**한다. (예: "낙인이론은 처벌을 정체성 개입으로 재해석한 이론이다") — 링크만 나열하지 않는다.
- 자기완결: "위 방식"류 문맥 의존 참조 대신 `[[노드명]]`.
- frontmatter 최소주의: confidence·status 라벨 없음. superseded와 승격 메타(승격일·출처 스코프)만 엔진이 기입.
- **용어 원칙**: CS·인지과학에서 원어가 통용되는 개념은 원어로(leaf, eviction, export staging, dormant), 자연스러운 관용 한국어가 있으면 한국어로(도마, 그물, 서명, 승격, 응고), **번역투 조어 금지**.

## §6. 명명·분류 권한 구배

| 층위 | 예 | 권한 |
|---|---|---|
| 최중심 | 링 이름, 게이트 규칙, 술어 | 원소별 비준 (사용자) |
| 중간 | Subject 최상위 스코프 신설·명명 | **승인제** — 에이전트 신청, 사용자 승인 |
| 주변 | 스코프 내부 하위 분화, 노트 배치, 임시명 | 에이전트 자율 + 사용자 사후 수정권 |
| 그물 밖 | 코드 스코프 내부 | 에이전트 영토 |

## §7. 판례 대장 (자율권의 성장 기록)

> 승인이 반복되어 패턴이 되면, 명시적 권한 부여를 여기에 기록한다. 확대는 기록으로만, 회수 가능. 서명(헌법 제5조 3항)은 판례 대상이 아니다.

| 날짜 | 부여된 자율권 | 근거 판례 |
|---|---|---|
| (없음 — 보수에서 출발) | | |

## §8. 심판 장부

- 사건: {쌍, 판정(open/resolved/preserved/기각), 기각 사유(대항·별개·중복·관점차), 판정일}.
- 저장: contradicts 엣지(사건 상태 포함) 또는 엔진 DB(기각 기록). 그물의 내용은 전자만.

## §9. 에이전트 세션 규칙 (요약)

- 세션 정리 시: 후보 제출(§1) 외에 vault에 쓰지 않는다. 레포 지식은 그 레포에.
- LTM 직접 쓰기 금지 — 승격 실행 대행만(§4).
- 애매하면 승인제(헌법 제10조).
