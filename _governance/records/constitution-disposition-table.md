# 구 헌법 처분표 (v4 — GPT 3차 교차 검토 반영)

> **규율 1 (무침묵)**: 모든 조문은 **계승 / 대체 / 폐지 / 이행** 중 하나 +
> 근거 판정 + 후계 위치. 이연-결부 행은 예약이지 침묵이 아니다.
> **규율 2 (탈방어·무역사)**: 이 표와 심의 기록은 과거를 참조하지만, **산출될
> 헌법 본문은 과거·폐지 개념·논쟁을 참조하지 않는다.** 부정문은 행동·경계를
> 규율할 때만 허용(규범), 폐지 개념의 부재 서술은 금지(방어). 계보는 본문이
> 아니라 frontmatter 배선이 진다: 구판 `replaces` + 심의·경위 연결은 【대기 ⑤】.
> **규율 3 (상태 표기)**: 각 처분·후계는 세 상태 중 하나를 갖는다 —
> 【확정】사용자 가결 완료(근거 B.1-n 등) / 【대기 n】사용자 판정 대기(말미
> 목록 번호) / 【조건부】다른 원소 비준 시 발화. 무표기는 【확정】.

## 조문별 처분

### 전문 (머리말) — **대체·이연**
- second brain 정체성·3층 구조 → **폐지·대체** (목적 전환 + Space 구조).
- 「모든 조항은 원소별 비준으로 성립한다」 → **계승**.
- 경위·역사 링크 → **본문에서 삭제** (무역사 원칙). 계보의 frontmatter 배선
  방식은 【대기 ⑤】: 구판 `replaces`는 확정(시행령 §17.2 열거 필드),
  심의·경위 기록의 연결 수단은 판정 대기 — §17.2는 「열거되지 않은 필드는
  보존할 수 있으나, 엔진은 이를 문서의 규범적 지위·비준·계보·상위 정본
  관계에 산입하지 않는다」이므로 `supported-by`를 그대로 쓰면 계보 의도가
  컴파일되지 않는다.
- 지칭 규율 → **계승** (Space/공간·scope/노드로 재서술).
- **이연**: 목적 문안(A1)은 업무 열거 없는 일반 문장으로 전문 작성 시 확정.
  탈방어: 「~가 아니라」류 대조 서술 없이 무엇인지만 쓴다.

### 제1조 — 이름과 주어
- 이름 → **계승** (osk-system 역사적 고유명사 유지 **가결** [B.1-14]. 재명명은
  첫 정식 릴리스 후 별도 원소).
- 주어 문장 → **대체**: 소유(사용자)·운용(에이전트)·표상 대상과 최종 권위
  (사용자)의 3분 서술. 주권 실질은 계승.

### 제2조 — 지식의 정의
- 1항 (연결을 통한 성장) → **계승**.
- 2항 (연속 스펙트럼) → **계승·수정** — 중심성은 공간별 창발, 교차 다리 별도.
- 3항 (O→S→K 경로) → **폐지·대체** — 후계는 **경로와 권위의 직교 분리**:
  ① 일반 기억 경로: 포착 → 가공(기록→모델 파생) → 내구화 판별【대기 ②】 →
  공간 배정. ② 서명: 어느 공간의 노드에든 가능한 상태 확인 — 경로의 단계가
  아니다. ③ 가결: User Model Space 적격 후보에 대한 사용자 전속 권위 사건 —
  경로의 종착이 아니라 직교 축. [v3 정정: 단일 파이프라인 오독 제거]

### 제3조 — Knowledge Layer — **폐지·대체**
- K층·Domain 저장 조직 → **폐지**. 후계: 파생 뷰(비권위·derived 표시) /
  사용자 지식 조직 기능 → User Model Space + 가결 효력.
- 사용자 명명권 → 뷰의 이름·pin으로 계승.

### 제4조 — Sensemaking Layer — **대체 (실질 계승)**
- Sense Space: sense 단위 응집·증류·자동화 기본·형성 중 수정 → **계승**.
  locality 단서 → 계승 (랭킹·큐레이션 자질).
- **Sense 다중 소속 → 【대기 ①】 (별도 원소)** — flat 국면의 미비준 잔재로
  확인됨. 판정 전 기본값: **단일 정본 Sense 소속 + 교차 링크·파생 보조 뷰**
  (구 4조 2~3항 실질 유지).

### 제5조 — Observation Layer — **대체**
- Scope Space: Scope 정의·출처 결속·locality 보존 → **계승**.
- 신설: `_raw/` — **Space가 아니라 각 scope 아래의 원자료 보관 구획.**
  포착은 **시스템이 참여한 세션에 한하며**(생활 감시 아님) 대화·행위 로그를
  전량 기록 / 작업 중 읽은 파일 전문을 재복제하지 않음 / 그래프 노드·기본
  연합 검색·중심성·충돌 스캔 비산입 / 명시 회상으로 접근 가능 / **마감된
  raw는 불변이며 private-only로 보존하고, 시스템은 그 영구 삭제를 발의하거나
  수행하지 않는다**(정리는 무손실 콜드 티어 이동 — 시행령). [B.1-1~2,
  v4 보강: 배치표와 조문 행의 불일치 제거]
- 비밀값 → **확정** [B.1-3, 사용자 축자 「뒤집는것 맞음. 정규식 절충안만
  제한적으로 허용」]: 전면 마스킹 없음(구 2026-06-19 판례의 명시적 번복),
  고위험 정형 패턴 정규식 필터만 제한 허용. 구체 패턴 목록은 mechanism 소관.
  번복 등재는 시행령 처분표에서.
- 3항 (현행 정본 / 고정 스냅샷) → **이연-결부** (frontmatter·kind 세부).

### 제6조 — Workbench — **계승 (헌법 소관분)**
- Space가 아닌 임시 작업 공간으로 존치 [B.1-14]. 헌법이 계승하는 것:
  **전역 검색 제외 + 내구 노드의 Workbench 참조 금지 + 중심성 비산입.**
- 교차 열람 차단·비인용(구 시행령 소관) → 시행령 처분표로 이관.
- 이관 검토 → **대체**: 펌프(보고·증류·상정). Workbench(진행 중 임시 상태)와
  _raw(마감된 세션 로그)의 구별 신설.

### 제7조 — 에이전트 기록 — **대체 (신 체계의 심장으로 확대)**
- 사용자 모델 제도 → **모듈식 User Model Space로 재구성·확대** [v4 윤문:
  퇴역 어휘 「승격」 제거]. UMS의 완전 정의는 B.1-7 그대로:
  「사용자에 관한 ①가공물(다이제스트와 파생 조망) ②잠정·확인 모델 ③가결로
  부여된 권위 효력을 두며, **원 세션 기록은 두지 않는다**(각 scope의 _raw에
  있다). 사용자가 직접 쓴 정규화 문서는 `author: user` 모델로 즉시 둔다.」
  default 모듈 6종·registry 세부는 시행령으로. [v3 보강: 정의 전문 편입]
- 1항 말미 (에이전트 지식의 관측 격리) → **폐지** — 후계: 「에이전트가 만든
  이해도 내구화 판별과 공간 배정을 동등하게 받아 Scope·Sense·User Model
  Space의 1급 모델이 될 수 있다. 저작 주체는 배정 기준이 아니다.」 보호는
  가결 축이 승계(미가결 무권위·무행동권한). [v3 정정: Sense 전속 문구 제거]
- 2항 (관측/잠정 추론 구별) → **계승** (+자기강화 금지).
- 3항 (제자리 갱신)·4항 (정본 하나) → **대체**: 정련은 **미가결 모델에 한함**
  (가결본의 갱신 권원은 사용자), raw는 동결, 가결 사건은 append-only. 단일
  정본 문서 → **중복 주장을 막는 정본 공간**(모듈식 UMS). 번복 목록 등재.
- 5항 (서명된 상태로만 진입) → **대체** — 가결로만 권위 효력.
- 6항 (충돌 시 서명 우선) → **계승·층화** [v3 정정: 절대 규칙 아님]:
  ① 사용자에 관한 서술 모델 간 충돌 — 가결 표상이 미가결 추론에 기본 우선.
  ② 사용자의 현재 직접 지시·정정이 기존 규칙을 **명시적으로** 수정·회수하면
  즉시 효력, 원장 갱신·사건 기록이 후속. ③ 적용 규칙 간 우선순위 불명·행동
  권한 불명 — fail-closed. [v4: 전역 우선이 아니라 명시 수정·회수에 한정]
- 7항 (스냅샷 참조 의무) → **폐지** — 살아있는 참조 + 사건화.
- 협업 기록 → scope 기억으로 흡수.

### 제8조 — 증류와 승격
- 1항 → **혼합**: 증류(기록→모델 파생) 재정의 계승 + 승격 폐지(어휘는 용어
  이행 표로).
- 2항 중복 금지 → **계승** — 「일반화는 근거를 이동·개작하지 않고 새 노드로
  생성하며 복제하지 않는다」로 재서술.
- 3항 판별 3문 → **대체 — 두 관문 분리 【대기 ②】**:
  ① **내구화 판별** — 미래 검색·판단·감사·작업 연결을 실질적으로 바꾸는가
  (포착→가공→내구화의 관문). ② **공간 배정** — scope 한정 / 범-scope /
  사용자 표상. 구 ①(성숙)은 모델의 잠정성 규율로.

### 제9조 — 서명
- 1~3항 (서명·상태 결속·불추정) → **계승** (확인 제도).
- **가결 제도 신설** — 서명의 확장이 아니라 별도 제도·별도 사건형. 효력은
  2분화 [v3 보강]: ① 모든 가결 — 그 표상을 사용자에 관한 **확정 전제**로
  사용할 수 있게 한다. ② **위임·제약형 가결만** — 행동 권한 또는 행동 제한을
  생성한다. 그 밖의 가결(생활 패턴·작업 일지 등)은 행동 권한을 만들지 않는다
  [B.1-6 「모듈은 행동 권한을 만들지 않는다」의 일반화]. append-only 원장,
  회수 즉시 효력.
- 4항 저작 → **계승** (공통 계약·파일 정본·해시 내용물에 저작 명시). 표기
  형식 세부는 **이연-결부**.

### 제10조 — Link와 Predicate Edge
- 1항 포함 위상 → **대체** + **공통 노드 조항 신설** [v3 문안 교정]:
  「모든 내구 노드는 생성 시 자동으로 불변 ID를 받는다. 디렉토리 경로는
  Space·Scope 소속의 정본이고, ID는 노드 동일성의 정본이다. 경로 이동은
  소속을 바꾸되 서명·가결·권위를 부여하거나 회수하지 않는다. 중심성은 이동
  후의 실제 의존 그래프에서 재계산하며, 이동 자체에 가산·감산을 부여하지
  않는다.」 [경계 정밀화의 조문화. 공간별 중심성과의 모순 제거 — 「불변」이
  아니라 「이동 보너스·페널티 없음」]
- 2항 (Link=약한 기본 가중) → **폐지** — 자유 링크는 검색 신호로만, 의존은
  typed bridge만 산입.
- 3항 술어 3종 → **대체·이연-결부** [v3 표기 정밀화]: **유형 있는 파생 다리**
  신설은 확정(기록→모델 배선 의무 포함) — 정확한 술어 명칭(잠정 derived-from)
  은 술어 목록과 함께 초안 단계 확정. replaces 계승 확정. contradicts의
  사건부 투영 흡수, supported-by 존폐는 초안 단계 확정.
- 4항 등급 모델 → **대체** — 공간·종류별 엣지 자격과 가결 효력의 재배정으로
  재서술.
- 5항 술어 자격 원칙 → **계승**.
- 6항 참조·전파 방향 → **계승** — 방향 있는 무효화, 전파는 공간 다리를 건넌다.

### 제11조 — 신뢰
- 1항 → **계승·수정** — 신뢰 점수 금지 계승, 사건 상태 표기는 사건부의 투영
  으로 허용.
- 2항 (중심성=개정 비용) → **계승** — 공간별 계산·교차 하중 별도.
- 신설 2문 [B.1-10 가결분, v3 등재 — 종전 누락]: 「**보존과 주의를 분리한다.**
  **주의 표면은 유한하다.**」 노출 조절·pin registry·브리핑 채널은 시행령으로.
- 3항 전단 (미서명 무중심성) → **폐지** (번복 가결 [B.1-9]). 후단(열람 표기·
  강등)은 의무형으로 **계승**. [v3: 요약표 오분류 정정 — 후단은 계승 행]
- 4항 재검토 전파 → **대체 【대기 ③】**: 트리거를 「재서명」에서 **「유효한
  의존 대상의 관련 상태 변경」**으로 일반화 — 미서명 중심성 가결의 필연 귀결.
  서명·가결 변경은 별도의 권위 효과. 봉인 불파괴 원칙은 계승. 번복 목록 등재.

### 제12조 — 정합성 검사
- 1항 → **계승**, 주기 세부는 이연-결부 (사건 생애주기).
- 2항 (입건≠확정) → **계승**.
- 3항 (해소 비자동) → **계승 + A3 【조건부】**: A3(에이전트 잠정 처분)가 별도
  원소로 비준되면 그 시점에 **명시적 대체**로 전환. 조문 어휘: 가결(사용자
  전속)과 에이전트 잠정 처분(agent disposition — 무기판력·무권위)은 완전 분리.
- 4항 라우팅 → **계승 + 조건부 신설** [v3 정정: 사용자/A3 분리]:
  ① 사용자 심의 — 출구는 기각·개정·존치, **전면 계승** (구 12조 4항 그대로).
  ② A3 에이전트 처분 — 파급 규모 임계 이상 사건은 개정 없이 병존·보류만
  [B.3-4] — **A3 원소 비준 시에만 발화하는 조건부 제한**이며 사용자 권한을
  제약하지 않는다. ③ 가결 항목 당사 사건 — 사용자 전속 [B.3-2].
- 5항 → **계승** — 기판력은 사용자 판정에만.
- 보완 신설: 기록 대 기록 불일치는 재관측·출처 확인 채널로 [B.1-12].

### 제13조 — 주권
- 1~4항 → **계승**.
- 5항 (직접 저작 예외) → **계승·재서술**: 직접 쓰기는 자유이되 **공간 허용
  종류와 가결 관문을 우회하지 않는다** (구 「서명 규칙은 예외가 아니다」의
  구조 승계).
- 6항 (정의·신념은 사용자의 말) → **계승·재서술**: 사용자의 직접 정의·신념
  **원문 인용에 한정**. 에이전트 추론은 agent-authored 모델로 분리.

### 제14조 — 개정
- 1항 (원소별 비준)·2항 (계보·체제 교체·보존) → **계승**.
- 3항 (재통과) → **이행** — 아래 부칙 요소.

## 이행 부칙 요소 (14조 3항의 후계)

1. **사건형 분리 【대기 ④】**: 구 frontmatter 서명은
   `legacy-signature-confirmation` 사건으로 이관 — **확인 효력만 가지며 권위를
   만들지 않는다.** 확인된 권한 후보의 **초기 seed는 판례 대장의 명시적 위임
   4행**이다. 이행 전수조사에서 발견된 다른 명시적 지속 위임·제약(판례 대장
   밖 결정 기록·현재 유효한 지속 지시)도 **같은 판정 절차**(항목별 검토 후
   사용자 비준)를 거쳐야만 grant 등재된다. 통치 문서가 부여하는 일반 권한은
   새 통치 문서의 비준으로 다시 성립하므로 이관 대상이 아니다. 소급 권한
   확대 금지. [v3: seed/전수조사 구별 — 「4행만」의 모집단 단정 해제]
2. **활성화 기록**: 현재 부존재(G2b 미선언·RELEASE.yaml 없음) — 이행 시점에
   실존 목록을 확인해 등재. 존재를 전제하지 않는다.
3. **구 코퍼스 이행**: 이행 실행 직전의 고정 스냅샷을 **migration manifest**에
   기록(노드·엣지 수·술어 분포 — 수치는 조문에 기재하지 않음). 공간·역할
   재분류, 매핑 없는 구 술어 엣지는 즉시 폐기하지 않고 **원형 archive + 판정
   로그**를 남긴 뒤 자유 링크 강등 또는 폐기 판정. 미가결 신분 배치.
4. **호환 뷰**: O/S/K 명칭은 이행기 호환 뷰로만.
5. **등재 거부 출구**: 사용자가 창설 등재를 거부한 항목은 미가결 강등.

## 헌법 초안 작성 규율 (탈방어 점검표)

- 대조 서술 금지: 「~가 아니라」·「~와 달리」로 폐지 개념과 대비하지 않는다.
- 부재 선언 금지: 폐지된 개념(K층·승격·휴면 등)은 언급 자체를 하지 않는다.
- 판례·역사 참조 금지: 근거·경위는 심의 기록과 주석이 진다. 계보는 frontmatter
  배선만 — 배선 수단은 【대기 ⑤】.
- 자기 정당화 금지: 「왜냐하면」류 근거 절은 조문에 두지 않는다.
- 부정문 허용 기준: 행동·경계를 규율하는 금지 규범만
  (예: 영구 삭제 발의 금지, 원 세션 기록의 UMS 배치 금지).
